### 5.2 三链路与 Advisor 链序

**共享件**：`smartRoutingChatModel`、`agentChatMemory`、`RetrievalContext` 参数链、安全/配额/审计 Advisor、`ToolCallingAdvisor(1000)`（tool/agent 共享）。**隔离件**：ChatClient Bean、工具集、SSE 帧形态、`toolContext` 组装点。

|---|---|---|---|---|---|
| 10 | `AuditTraceAdvisor` | ✅ | ✅ | ✅ | 全链路审计（含 REJECTED/ERROR） |
| 30 | `TokenBudgetAdvisor` | ✅ | ✅ | ✅ | 租户日 Token 预算 |
| 100 | `RateLimitAdvisor` | ✅ | ✅ | ✅ | 租户令牌桶（429） |
| 110 | `OutputGuardrailAdvisor` | ✅ | ✅ | ✅ | 输出词表/金丝雀；流式增量放行 + REPLACE |

### 5.3 Java 21 虚拟线程应用策略

| 应用场景 | 并发模型 | 收益 |
|---------|---------|------|
| 混合检索（向量+BM25[+Graph]） | 共享 `hybridRetrievalExecutor` + Future | 多路并行，总延迟 = max(各路)；单路 5s 超时非打断式取消 |
| 文档 ETL 管道 | 虚拟线程异步 | Web 线程立即返回；进度经 WebSocket |
| SSE 流式推送 | `Flux` + Sinks 旁路合流 | 非阻塞 I/O；心跳防中间层掐断 |
| 图谱抽取 / 回填 | 虚拟线程有界并发 + 令牌桶 + 信号量 | 供应商压力有界；双档分桶 |
| 批量向量化 / 语境增强 | 10 条/批 + 有界并发 8 | 供应商批限制与吞吐平衡 |

**关键注意事项**：确保底层 HTTP 客户端（RestClient/WebClient）支持虚拟线程，避免 synchronized 块从而导致 Pinning。
