## 2. 差距与演进方向

1. **文档级 ACL 缺位**——租户内所有文档全员可见；部门文档（薪酬制度/合同库）场景不通；
2. **GraphRAG 单跳**——多跳推理靠 chunk 内容补足第二跳；社区级摘要/全局性问题上限受限；
3. **Reranker/Embedding 全云 API**——成本与延迟（外呼 ~100ms/次）+ 合规面；
4. **表格/版式富文档检索弱**——文本化切分损失表格结构语义；扫描件经 OCR 后检索质量降档；
5. **多知识库路由**（5.5 归档）——单库场景等待第二知识库触发；
6. **知识保鲜靠人工**——过期/矛盾内容无自动检测。

## 4. 设计方案

### 4.1 文档级 ACL（3.11 复活——部门/角色隔离）

- **模型**：文档级 `visibility`（全员 / 部门集 / 角色集）；chunk metadata 冗余 ACL 标签（三存储面同步——对齐 heading_path 先例）；
- **过滤**：检索器查询期注入用户部门/角色（RetrievalContext 扩展）→ 向量/ES/Graph 三路同过滤（租户过滤同模式）；`get_document`/MCP/A2A 面同守卫；
- **标注**：上传时指定 + 管理端改（改动触发该文档索引 ACL 标签重写——轻量 reindex 路径）；
- **验收**：跨部门不可见 E2E（对齐跨租户零触达用例形态）+ Golden ACL 专项集。

### 4.2 GraphRAG 进阶（社区摘要 + 摘要索引）

- **抽取期**：实体抽取管道追加社区聚类（label propagation 轻量算法，Neo4j GDS 或自实现）+ 社区摘要生成（LLM 离线一次性，令牌桶内）；
- **检索期**：图路查询 = 实体匹配（现状）+ **社区摘要节点命中**（摘要嵌入同索引）——全局性/总结性问题（「信息安全制度整体框架」）命中率提升，查询期仍零 LLM；
- **评估**：多跳专项集扩全局问题子集，门禁对照。

### 4.3 Reranker/Embedding 本地化（双形态配置化）

- `rag.rerank.provider=cloud|local` / `rag.embedding.provider=cloud|local`（本地 = vLLM 端点 BGE 系）；
- 切换即生效（后端抽象已有），A/B 门禁对照质量（召回/延迟/成本三读数）；与 03 分册本地模型形态共享 vLLM 部署。

### 4.4 视觉检索路（ColPali 试点，第四路）

- 试点形态：图表密集 PDF 子集页面图像化 + ColPali 索引 → 图像路并入 RRF（`rag.retrieval.visual.enabled` 缺省关——条件装配纪律）；
- 判据：表格/版式类查询的 Recall 增益 ≥5pp 才转正，否则试点归档。

### 4.5 多知识库动态路由（5.5 复活）

- 触发 = 第二知识库接入：领域独立 collection（向量库 multi-collection + ES 索引前缀）+ 领域路由层（意图分类扩展领域维度——440 路由器天然挂接点）；跨库问答 = 并行检索全域 RRF；
- 与 ACL 正交（域内仍有部门隔离）。

### 4.6 知识自动运营

- **过期检测**：文档级 `expires_at` 元数据 + 到期扫描（ETL 终态帧调度器复用）→ 管理端到期清单（下线/续期/重审三操作）；
- **矛盾检测**：同实体跨文档陈述对抽取（图路实体锚点复用）→ LLM 判矛盾（Judge 通道）→ Bad Case 队列流转（既有闭环）；
- **质量看板**：引用率/点踩率按文档聚合（审计 trace 已有数据面）→ 低质知识 Top 清单驱动采编。
