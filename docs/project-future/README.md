## 优先级与依赖总览

```
真实工具链（01）────┬──▶ 跨链 mode=auto（5.4-A 复活）
                    └──▶ MCP Host 化（02）   ← 01 与 02 互补：MCP Server 是工具接入的主流供给形态

训练闭环（03）────── 自持（反馈数据已在积累，导出管道已就绪）
检索演进（04）────── 按语料形态择机（ACL 与多知识库由业务触发）
规模化（05）──────── 由并发规模触发（当前单机余量充足）
```

**建议优先序**（价值/成本比）：① 01 真实工具链（解锁 Agent 面全部价值）→ ② 03 训练闭环（数据飞轮自持运转）→ ③ 02/04 按外部需求触发 → ④ 05 最后（规模化前提 = 业务负载真实到来）。
