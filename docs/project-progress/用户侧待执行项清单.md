## F1 · Flyway ECS 基线演练与登记核验（簇⑥ 批1a，v2.54）

**目的**：现网库接入 Flyway 迁移版本化前的受控演练（4.11 验收组成：DB 迁移版本化 100% 的第一步）。

**前置**：部署含 v2.54 Flyway 的构建产物（fat jar 或后续批1b 镜像）。配置默认 `spring.flyway.baseline-on-migrate=true` + `baseline-version=0`，无需额外环境变量。

**步骤**：
1. ⚠️ **先备份现网库**：`pg_dump -Fc` 一份留档（原生 PG，宿主机执行）；
2. （可选但推荐）**备份库演练**：`createdb kb_rag_agent_flyway_drill` + `pg_restore` 恢复备份 → kb-api 以 `DB_URL` 指向演练库启动一次 → 观察启动日志 Flyway 段（baseline + V1 应用）；
3. 校验演练库：`psql -d kb_rag_agent_flyway_drill -c "SELECT installed_rank, version, description, success FROM flyway_schema_history ORDER BY installed_rank;"` —— 预期两行：version=0（baseline）与 version=1（baseline_schema），success 均 t；表结构零变化（V1 全 IF NOT EXISTS 幂等 no-op）；
4. 演练通过后体现网：正常启动 kb-api（指向现网库），首跑自动完成同样的 baseline 登记；
5. 现网校验同上 SQL。

**预期回传**：flyway_schema_history 两行截图/文本 + 启动日志 Flyway 段关键行。

**回滚**：删除 flyway_schema_history 表即回到接入前状态（`spring.flyway.enabled=false` 亦可整体关闭，env `FLYWAY_ENABLED=false`）。
