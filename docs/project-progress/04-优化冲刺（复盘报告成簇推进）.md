- **D1 流式 token 计账（include_usage）**（✅ 2026-08-11）：
  - 源码核验：deepseek starter `DeepSeekApi.ChatCompletionRequest` record 无 stream_options 组件、`DeepSeekChatOptions` 无 streamUsage（2.0.0 jar 字节码）——starter 形态下 include_usage 不可开，流式消耗系统性漏算（配额账本 + 审计 token 列双面，生产对话以流式为主）

  - 链路收益零改动：TokenBudgetAdvisor.after() / AuditTraceAdvisor 末块 usage 回写逻辑不变，include_usage 开启即生效（usage 缺失仍 0 降级，只少计不击穿）
