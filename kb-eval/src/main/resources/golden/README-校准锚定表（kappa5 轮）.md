## 〇、总纪律（全维适用）

1. **穷尽核查**：判「无依据 / NOT_SUPPORTED / YES / DRIFTED」前，须逐条穷尽
   全部参考资料条目（含表格/枚举/字段值/推算值）；未穷尽不得判负。
2. **判负有据、判高亦有据**：给出高分前，先逐条确认每个事实陈述/要点的证据
   位置；证据缺位时不因「答案方向正确、流畅、切题」而抬分。κ 复校-③ 实证
   分歧方向系统性偏高——高分方向须逐条验证后方可给出。
3. **维度独立**：同一事实面在不同维度口径下结论可不同（典型：F 容忍逻辑外推
   而 HR 计其无依据），逐维按各自口径独立判定，不互推。

## 一、faithfulness（1-5）

**分档锚**：
- 5 = 每个事实陈述均有资料依据，零编造、零外部知识；
- 4 = 内容全部有依据，仅存引用编号/归属瑕疵，或仅个别轻微外推（资料陈述的
  逻辑延伸，不引入新事实、不构成误导）；
- 3 = 少量无依据陈述——**含「领域常识」型外部知识混入**（即使常识本身正确、
  资料未载即无依据）；
- 1-2 = 明确编造、与资料矛盾，或无依据陈述达**整节/整条规模**。

**worked example**：
1. **cross-04（MULTI_DOC 跨文档聚合族，Judge=2）**：回答四节中两节的行为清单
   条目在全部资料中完全不存在（整节规模编造），其余两节有依据 → 判 2 分。
   **要点**：无依据陈述达整节规模时不得高于 2 分；「其余部分有依据」「整体
   方向正确」不构成抬分理由。
2. **sec-09（REASONING 制度族，Judge=3）**：核心结论有明确依据，但推理链上一
   关键前提（分级归类与「典型示例」式断言）未被其所引资料条目覆盖 → 判 3 分。
   **要点**：结论正确不豁免前提核查；关键前提无依据时非 5 分档。
3. **k8s-13（REASONING 运维族，Judge=4）**：核心结论直接源自资料陈述；补充
   解释为资料语义的逻辑延伸（未引入新事实）→ 判 4 分。**要点**：转述级逻辑
   延伸 ≠ 编造；但注意 HR 维度口径（见四）。
4. **k8s-14（REASONING 运维族，Judge=3）**：主体忠实，补充说明混入一条领域
   常识型外部知识陈述 → 判 3 分。**要点**：与 k8s-13 对照——资料陈述的逻辑
   延伸（4 分）vs 引入外部知识（3 分），判据 = 新内容能否在资料中找到出处。
5. **fin-15（REASONING 财税族，Judge=4）**：内容全部有依据，唯引用编号指向
   错误条目（内容实际由另一条目支撑）→ 判 4 分而非 5 分。**要点**：归属瑕疵
   是唯一减分项；内容真实性不因编号错误推翻。

## 二、answer_correctness（1-5）

**判据（与 Judge 同源）**：对照理想回答的事实要点覆盖与矛盾——不要求措辞一致。
5 = 要点完全覆盖且无矛盾；4 = 主要要点覆盖、个别次要遗漏、无矛盾；3 = 约半数
覆盖或少量不一致；2 = 多数要点遗漏或明显矛盾；1 = 基本未覆盖或严重矛盾。

**worked example**：
1. **cross-02（MULTI_DOC 期限族，Judge=2）**：理想回答含五组要点簇（结果查询
   时限 / 分级事件报告时限 / 发票认证时限 / 备份周期 / 质保期）；模型回答仅覆盖
   其中一组（发票认证时限），其余内容全部是理想回答要点之外的其他期限事实
   → 判 2 分（多数要点遗漏）。**要点**：AC 只计理想回答要点覆盖——答案的切题度、
   流畅度、要点外的自洽事实（即使真实且相关）均不构成加分；不得因「答案方向
   正确、内容丰富」给 4 分以上。
2. **理想回答隔离**：理想回答仅出现在 AC 判读块（M2 物理隔离）；严禁将其用作
   F/CA/HR/NRob 的证据或印象来源。

## 三、citation_attribution（SUPPORTED / NOT_SUPPORTED）

**判据**：主判 = 引用陈述的内容是否被**某条**参考资料实质支撑。编号标注偏差
（陈述实由其他条目支撑）不单独判负；仅当陈述不被任何资料支撑、与资料矛盾、
或归属造成误导时判 NOT_SUPPORTED；回答未发出任何引用 → NOT_SUPPORTED。

**worked example**：
1. **fin-15（Judge=SUPPORTED）**：陈述内容有资料条目实质支撑，但引用编号指向
   了另一（不支撑该陈述的）条目 → SUPPORTED。**要点**：张冠李戴属引用准确性
   瑕疵（已在 F 维以 4 分反映），不改变内容支撑判定。
2. **sec-09（Judge=NOT_SUPPORTED）**：陈述所引条目仅涉及**相关话题**（采集
   原则与加密要求），未实质覆盖陈述本身（分级定义与典型示例断言）→
   NOT_SUPPORTED。**要点**：「话题相关」≠「内容支撑」——支撑要求条目实质
   覆盖陈述的事实断言，而非同域出现。

## 四、hallucination（YES / NO）

**判据**：回答含 ≥1 条参考资料无依据的事实声明 → YES；判 NO 前须逐条声明
穷尽核查全部资料条目。转述/归纳语义一致、资料数值直接推算算有依据。

**关键边界（F/HR 不对称）**：资料陈述的逻辑外推在 F 口径容忍（仍可 4 分），
但同批外推声明在 HR 口径即「无依据声明」→ YES。两维独立计分，不因 F 高而
推 HR=NO。

**worked example**：
1. **k8s-13（Judge=HAS，比率 33%）**：回答中的外推性解释声明非资料字面事实
   → HAS。**要点**：F=4 与 HR=YES 并存是口径的正常形态。
2. **k8s-14（Judge=HAS，比率 14%）**：唯一一条外部知识声明无依据 → HAS。
   **要点**：一条即 YES，占比低不豁免。
3. **sec-09（Judge=HAS，比率 67%）**：关键前提声明无依据 → HAS（与 F 锚 2、
   CA 锚 2 同例三维演示——同一事实面在 F/CA/HR 三口径下的独立判定）。

## 五、noise_robustness（CONSISTENT / DRIFTED）——本轮口径澄清（裁决 c）

**判定对象** = 证据基事实结论与关键数据（忽略措辞、详略、引用编号差异）。

**判定程序（顺序执行）**：
1. 比对两回答证据基结论与关键数据是否改变/矛盾/稀释 → 是 → **DRIFTED**；
2. 提取「答案 B 独有内容」（B 有 A 无），对**全部资料条目逐项穷尽比对**
   （注意：混入的噪声证据亦在其中，以编号续接混入，材料中不可区分）：
   - 语义可映射任一资料条目（转述、部分采纳、数值照抄均算映射）= 噪声采纳
     → **DRIFTED**（一条即判）；
   - 不可映射任何资料条目 = 模型自生成（归忠实性/幻觉维度，**非漂移**），
     证据基结论一致时 → **CONSISTENT**。

**澄清点（针对 κ 复校-③ B 侧少数派标注）**：「单侧无依据内容不计漂移」**仅**
适用于第 2 步「不可映射任何资料条目」的情形；「源自噪声证据」以**语义可映射**
为准，不要求逐字采纳。旧口径「单侧无依据不计漂移」被过窄应用为「凡单侧新增
内容一律不计漂移」，本轮起以上述程序为准。
